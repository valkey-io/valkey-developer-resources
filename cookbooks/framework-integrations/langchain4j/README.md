# LangChain4j with Valkey

> Use Valkey as a vector embedding store in Java applications with LangChain4j — semantic search, metadata filtering, and RAG pipelines powered by the official `langchain4j-community-valkey` package.

| # | Cookbook | Description | Tags |

| 02 | <nobr>[Metadata Filtering](02-metadata-filtering.md)</nobr> | Combine vector similarity with TAG, NUMERIC, and TEXT metadata filters in a single query. | Intermediate, ~20 min, Java |
| 03 | <nobr>[RAG Pipeline](03-rag-pipeline.md)</nobr> | Build end-to-end Retrieval-Augmented Generation: chunk, embed, store in Valkey, and answer questions with context. | Intermediate, ~25 min, Java |
| 04 | <nobr>[Production Patterns](04-production.md)</nobr> | HNSW vs FLAT indexing, distance metrics, batch ingestion, connection management, and scaling. | Advanced, ~20 min, Java |
