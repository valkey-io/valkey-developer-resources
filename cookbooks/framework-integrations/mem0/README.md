# Mem0 + Valkey

> 3 cookbooks for using Mem0's intelligent memory layer with Valkey as the native vector store. From basic memory operations to production with ElastiCache.

## Cookbooks

| # | Cookbook | Description | Tags |
| --- | --- | --- | --- |
| 01 | <nobr>[Getting Started](01-getting-started.md)</nobr> | Install Mem0, configure the Valkey provider, add/search/retrieve memories for AI agents. | Beginner, ~15 min, Python |
| 02 | <nobr>[Multi-User Memory](02-multi-user-memory.md)</nobr> | Per-user, per-agent, and per-session memory isolation using Valkey TAG fields. | Intermediate, ~20 min, Python |
| 03 | <nobr>[Production with ElastiCache](03-production.md)</nobr> | Deploy with ElastiCache for Valkey 8.2+, HNSW tuning, TLS, monitoring. | Advanced, ~20 min, Python |
