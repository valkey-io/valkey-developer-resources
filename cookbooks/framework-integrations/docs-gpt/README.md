# DocsGPT + Valkey

> 2 cookbooks for using Valkey as the vector store backend in DocsGPT — an open-source AI assistant platform for document retrieval. Demonstrates document ingestion with vector embeddings and semantic search using `valkey-glide-sync` and valkey-search.

## Cookbooks

| # | Cookbook | Description | Tags |
| --- | --- | --- | --- |
| 01 | [Getting Started](01-getting-started.md) | Configure DocsGPT to use Valkey as the vector store, ingest documents, and run your first semantic search query. | Beginner, ~15 min, Python |
| 02 | [Document Ingestion & Retrieval](02-ingestion-and-retrieval.md) | Deep dive into the ingestion pipeline — chunking, embedding, HNSW indexing, and filtered vector search with source isolation. | Intermediate, ~20 min, Python |
