# Cognee + Valkey

> 3 cookbooks for using Cognee's AI memory and knowledge graph system with Valkey as the vector store backend. From basic setup to production with ElastiCache.

## Cookbooks

| # | Cookbook | Description | Tags |
| --- | --- | --- | --- |
| 01 | <nobr>[Getting Started](01-getting-started.md)</nobr> | Install Cognee, configure the Valkey adapter, add documents, build a knowledge graph, and search. | Beginner, ~15 min, Python |
| 02 | <nobr>[Knowledge Graph](02-knowledge-graph.md)</nobr> | How Cognee builds knowledge graphs on top of vector embeddings, search types, and multi-document relationships. | Intermediate, ~20 min, Python |
| 03 | <nobr>[Production with ElastiCache](03-production.md)</nobr> | Deploy with ElastiCache for Valkey, HNSW tuning, TLS, Bedrock configuration, and monitoring. | Advanced, ~20 min, Python |
