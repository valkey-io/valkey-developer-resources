# Pub/Sub &Streaming

> 6 production-ready cookbooks for real-time messaging with Valkey. From basic PUBLISH/SUBSCRIBE to distributed consumer groups with Valkey Streams.

## Cookbooks

| # | Cookbook | Description | Tags |
| --- | --- | --- | --- |
| 01 | <nobr>[Getting Started with Pub/Sub](01-getting-started.md)</nobr> | PUBLISH, SUBSCRIBE, and pattern matching. Your first real-time message in under 5 minutes. | Beginner, ~5 min, Python |
| 02 | <nobr>[Streaming LLM Tokens](02-streaming-llm-tokens.md)</nobr> | Buffer and broadcast token-by-token LLM responses to multiple clients via Pub/Sub. | Intermediate, ~15 min, Python |
| 03 | <nobr>[Valkey Streams Fundamentals](03-valkey-streams.md)</nobr> | XADD, XREAD, and XRANGE for durable, ordered message queues. Pub/Sub vs Streams - when to use which. | Intermediate, ~20 min, Python |
| 04 | <nobr>[Consumer Groups](04-consumer-groups.md)</nobr> | Distributed stream processing with XREADGROUP, acknowledgments, pending entries, and dead-letter handling. | Advanced, ~25 min, Python |
| 05 | <nobr>[Fan-Out Patterns](05-fan-out-patterns.md)</nobr> | One producer → many consumers. Multi-client delivery for AI agent events, notifications, and real-time dashboards. | Advanced, ~25 min, Python |
| 06 | <nobr>[Production Patterns](06-production.md)</nobr> | Backpressure with MAXLEN, monitoring with XINFO, reconnection strategies, and scaling patterns. | Advanced, ~30 min, Python |
