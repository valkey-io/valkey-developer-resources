# Valkey Samples

A list of curated resources with demos, tutorials and samples for Valkey.

## Cookbooks

- [Framework integrations](cookbooks/framework-integrations/README.md): Examples for
  connecting Valkey with application frameworks, including LangChain and LangGraph.
- [LangChain + Valkey](cookbooks/framework-integrations/langchain/README.md): Python
  cookbooks using LangGraph and the `langgraph-checkpoint-aws` package with Valkey
  for checkpoint persistence, response caching, and vector search.
