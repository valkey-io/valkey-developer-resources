## Maintainer Responsibilities

- Review and merge pull requests in a timely manner
- Ensure contributions meet the [acceptance criteria](CONTRIBUTING.md#acceptance-criteria)
- Enforce vendor neutrality and content quality standards
- Triage issues and guide contributors
- Participate in repository governance decisions

## Becoming a Maintainer

New maintainers are nominated through the following process:

1. **Consistent contribution** — the nominee has a track record of high-quality contributions to Valkey-Samples (PRs, reviews, issue triage)
2. **Nomination** — an existing maintainer or TSC member nominates the candidate by opening a discussion in the repository
3. **Consensus** — existing maintainers discuss the nomination. Approval requires consensus (no vetoes) from current maintainers
4. **TSC ratification** — the Valkey TSC ratifies the appointment
5. **Onboarding** — the new maintainer is added to this file and granted the necessary repository permissions

Maintainers who are inactive for an extended period may be moved to emeritus status by consensus of the remaining maintainers.
